# Wazuh

## Role

Wazuh is the security monitoring and detection component
of our mini-SOC.

## Responsibilities

- Monitor Windows and Active Directory
- Collect security logs
- Detect suspicious activity
- Generate security alerts
- Forward relevant alerts to TheHive

## Configuration

This directory contains selected Wazuh configurations,
custom rules, scripts, and documentation used in the SOC lab.

Sensitive information such as API keys, passwords,
certificates, and private keys is not included.

## Integration

Wazuh → TheHive
Wazuh → MISP
